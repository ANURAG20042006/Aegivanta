# PHASE 32 — THE DIAMOND MODEL OF INTRUSION ANALYSIS SPECIFICATION

## 1. The 4 Core Vertices

```
                 [ADVERSARY]
                 /         \
                /           \
               /             \
    [CAPABILITY]             [INFRASTRUCTURE]
               \             /
                \           /
                 \         /
                  [VICTIM]
```

- **Adversary**: Sponsoring nation or cybercrime organization.
- **Capability**: Malware payloads, zero-day exploits, living-off-the-land utilities.
- **Infrastructure**: Fast-flux DNS, bulletproof hosting, compromised SOHO routers.
- **Victim**: Targeted vertical sectors, geographic jurisdictions, and technology stacks.
