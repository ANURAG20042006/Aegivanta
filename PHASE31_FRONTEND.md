# PHASE 31 — FRONTEND ATTACK SURFACE CENTER

## 1. UI Tabs

`AttackSurfaceCenter.tsx` delivers a 6-tab enterprise interface:
1. **CTEM & ASM Overview**: Composite ASM Posture score, Gartner 5-Stage status, exposed asset counts, priority actions.
2. **External Asset Inventory**: Interactive inventory with cloud providers, open port tags, and SSL expiration countdowns.
3. **Dangling DNS & Takeover**: Subdomain takeover vulnerability cards with CNAME pointer verification.
4. **Dark Web Breach Intel**: Compromised credentials table with breach source and remediation triggers.
5. **Brand Protection**: Typosquatted lookalike domains with Levenshtein similarity scores and active MX indicators.
6. **CTEM Prioritization Matrix**: EPSS percentile, CVSS v3.1, CISA KEV weaponization status, and mobilization playbooks.
