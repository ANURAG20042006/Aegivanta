# PHASE 29 — SBOM 2.0 USER GUIDE

## 1. SBOM Generation & Export

Aegivanta generates compliant SBOM documents:
- **CycloneDX 1.5 JSON**: Default schema for modern vulnerability management.
- **SPDX 2.3 JSON**: Compliant with NTIA and US Executive Order 14028 requirements.
- **Package URLs (PURL)**: Standardized identifiers for Python (`pkg:pypi/`), Node (`pkg:npm/`), Go (`pkg:golang/`), and Maven (`pkg:maven/`).
