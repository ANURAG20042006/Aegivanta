# PHASE 36 — RELEASE NOTES (v36.0.0)

- **Microsegmentation & Software-Defined Perimeter (SDP)**: Zero Trust Network Access (ZTNA 2.0) with WireGuard/IPsec encrypted overlays.
- **Layer 4 & Layer 7 Isolation Policy Engine**: eBPF kernel isolation rules with trust score gating.
- **Continuous Device Trust Attestation**: Real-time evaluation of device health and velocity with dynamic session revocation.
- **Lateral Movement Interception**: Automated blocking and isolation of unauthorized inter-segment traversal attempts.
- **Interactive Segment Flow Mesh Visualizer**: Topology visualization of isolated security enclaves.
- **6-Tab Frontend Command Center**: Interactive `MicrosegmentationCenter.tsx` with policy creation and session termination.
- **Zero-Failure Verification**: 100% test pass rate across 8 test suites and clean Vite production build.
