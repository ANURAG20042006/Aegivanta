# PHASE 28 — FIDO2 & WEBAUTHN PASSKEYS

## 1. Passkey Implementation

1. **Hardware Bound**: Supports YubiKey, Google Titan, and Apple Touch ID / Windows Hello built-in authenticators.
2. **Phishing Resistance**: Cryptographically bound to origin domain (`https://aegivanta.io`).
3. **Admin Enforcement**: Mandatory passkey authentication for Super Admin and Cluster Admin roles.
