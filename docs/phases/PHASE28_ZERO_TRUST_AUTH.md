# PHASE 28 — CONTINUOUS ZERO TRUST AUTHORIZATION

## 1. Dynamic Authorization Factors

- **Identity Risk Score (0-100)**: Behavioral anomalies and ITDR alert history.
- **Endpoint Device Trust (0-100)**: MDM enrollment, disk encryption, EDR sensor health.
- **Network & Geo Velocity**: IP reputation and impossible travel checks.
- **Resource Criticality**: Target database, Kubernetes control plane, or financial ledger.
