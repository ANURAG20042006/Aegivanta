# PHASE 27 — FRONTEND CNAPP COMMAND CENTER

## 1. UI Components & Tabs

`CloudSecurityCenter.tsx` implements a 6-tab enterprise interface:
1. **CNAPP Overview**: Unified 0-100 posture score, connected account cards, priority remediation playbook.
2. **Multi-Cloud Inventory**: Real-time asset inventory table with provider badges and exposure indicators.
3. **CSPM & Compliance**: Open CIS benchmark misconfigurations with remediation steps.
4. **CWPP & Containers**: Live workload threat alerts, interactive quarantine controls, container SBOMs.
5. **KSPM & Serverless**: Kubernetes cluster health, interactive YAML manifest auditor, Lambda risk inspector.
6. **CIEM & Attack Paths**: Cloud IAM entitlement graphs, privilege escalation paths, blast radius.
