# PHASE 31 — GARTNER 5-STAGE CTEM FRAMEWORK SPECIFICATION

## 1. The 5 CTEM Lifecycle Stages

1. **Stage 1: Scoping**: Defines high-value assets, crown jewels, external domains, and IP ranges.
2. **Stage 2: Discovery**: Automatically enumerates subdomains, DNS records, open ports, and certificates.
3. **Stage 3: Prioritization**: Scores exposures combining CVSS v3.1 base score, EPSS exploit likelihood percentile, and CISA KEV real-world weaponization.
4. **Stage 4: Validation**: Validates external reachability through non-destructive automated probes.
5. **Stage 5: Mobilization**: Generates actionable SOAR playbooks, Jira remediation tickets, and IAM password reset tasks.
