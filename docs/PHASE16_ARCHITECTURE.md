## 2. Core Subsystems
1. **Detection Quality Subsystem**: Tenant-specific precision, recall, F1, false-positive rate, false-negative rate, MTTD, MTTA, MTTR, historical accuracy tracking.
2. **Intelligent Alert Deduplication**: SHA-256 fingerprinting, temporal correlation, alert grouping into unified incident campaigns without losing forensic evidence.
3. **Explainable Priority Scoring**: 0–100 score synthesized across 6 distinct risk dimensions with human-readable rationale.
4. **Immutable Incident Timeline**: Chronological security action ledger from first seen to resolution.
5. **Unified Investigation Search**: Bounded, indexed cross-entity search with query execution performance metrics.
6. **Telemetry Cost & Product Analytics**: High-volume sensor contribution profiling and storage optimization recommendations.
