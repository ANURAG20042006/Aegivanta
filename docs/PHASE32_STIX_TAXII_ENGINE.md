# PHASE 32 — STIX 2.1 & TAXII 2.1 INGESTION ENGINE SPECIFICATION

## 1. Supported STIX 2.1 Domain Objects (SDOs)

- **`indicator`**: Patterned observable (IP, domain, hash) with kill chain phase mapping.
- **`threat-actor`**: Profile including origin, aliases, motivation, and sophistication.
- **`malware`**: Tooling, ransomware strain, and command-and-control communication types.
- **`attack-pattern`**: MITRE ATT&CK technique IDs and execution mechanics.
- **`campaign`**: Grouping of related attack operations over time.
