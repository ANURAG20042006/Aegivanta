# SentinelAI — Threat Hunting & Investigation Guide

**Status**: Active  
**Component**: Advanced Threat Hunting Engine (`/threat-hunting`)

---

## 1. Overview

The SentinelAI Threat Hunting Engine allows SOC analysts and incident responders to perform hypothesis-driven, retroactive, and proactive queries across all security telemetry stored in SentinelAI.

---

## 2. Supported Hunting Entities

| Entity Name | Target Data Model | Key Filter Parameters | Use Case |
|---|---|---|---|
| **Security Flow Alerts** (`alerts`) | Flow classification alerts generated by CatBoost ML | `source_ip`, `destination_ip`, `attack_type`, `severity`, `time_range` | Investigate network ingress/egress anomalies |
| **Correlated Incidents** (`incidents`) | Correlated multi-alert incidents | `source_ip`, `destination_ip`, `attack_type`, `severity`, `status` | Trace coordinated attack vectors & incident lifecycle |
| **Threat Intel IOCs** (`iocs`) | Threat intelligence indicators (STIX / OpenCTI / AlienVault) | `ioc_type`, `keyword` | Search known malicious IPs, domains, and botnet C2 nodes |

---

## 3. Querying & Filter Syntax

### Time Horizons
- `1h`: Last 60 minutes
- `24h`: Last 24 hours (default)
- `7d`: Last 7 days
- `30d`: Last 30 days

### Filter Options
- **Source IP / CIDR**: Exact IP (e.g. `185.220.101.5`) or subnet search.
- **Destination IP**: Protected endpoint IP (e.g. `198.51.100.10`).
- **Attack Type**: Substring search across attack types (e.g. `DDoS`, `PortScan`, `Infiltration`, `SSH-Patator`).
- **Severity**: Exact severity filter (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`).

---

## 4. Saved Query Templates

1. Construct the desired search filter in the query builder.
2. Click **Save Query** in the top action bar.
3. Provide a clear descriptive template name (e.g., `High-Severity Port Scanners`).
4. Saved queries are immediately available in the left sidebar for instant one-click execution.

---

## 5. Security & Rate Limiting

- **Injection Defense**: All threat hunting queries are strictly parameterized using SQLAlchemy ORM bound expressions. Raw SQL execution is prohibited.
- **Rate Limiting**: Sliding window limit of 45 queries per minute per client.
- **RBAC**: Viewers can execute hunts; only Analysts and Admins can create saved query templates.
